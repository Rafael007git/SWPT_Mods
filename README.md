# SWPT Mods
A collection of my custom mods for SWPT game.

## Repository Contents
* **MegamorphLegFix** — Fixes:
1. Leg distortion below knee.
2. Lights attached to character skeletons becoming too bright when those characters are made tiny.

## How to Clone
To clone this repository along with all nested submodules, use the following command:
```bash
git clone --recurse-submodules git@github.com:Rafael007git/SWPT_Mods.git
```
